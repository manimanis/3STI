Question 1

Quelle est la différence fondamentale de comportement entre une balise de niveau bloc (ex. <div>, <p>) et une balise de niveau en-ligne (ex. <span>, <a>) ?

💡 Cliquez ici pour afficher la réponse
  • Élément bloc (display: block) : Occupe toute la largeur disponible de son conteneur, débute systématiquement sur une nouvelle ligne et accepte la définition de dimensions explicites (width, height, marges et espacements verticaux).
  • Élément en-ligne (display: inline) : Se glisse naturellement au sein du flux textuel sur la même ligne, n'occupe que la largeur exacte de son contenu et ignore les propriétés width et height.

Question 2

Quelle est la différence entre l'attribut booléen hidden en HTML5 et la déclaration CSS display: none; ?

💡 Cliquez ici pour afficher la réponse

Sur le plan visuel, le résultat est équivalent : l'élément disparaît complètement de l'affichage et ne réserve aucun espace. Toutefois, hidden est un attribut sémantique natif HTML5 directement compris par le navigateur et les lecteurs d'écran sans nécessiter de code CSS, tandis que display: none; est une règle de style purement cosmétique définie dans une feuille de style.

Question 3

À quoi sert l'attribut target sur un lien hypertexte <a>, et comment peut-on le relier à un <iframe> ?

💡 Cliquez ici pour afficher la réponse

L'attribut target précise le contexte de navigation récepteur où doit s'ouvrir le lien. En attribuant à target la valeur du nom (attribut name) d'un <iframe>, le clic sur ce lien charge immédiatement la page dans ce cadre sans recharger la page principale.

Conteneurs & Attributs HTML5

Cadres intégrés : <iframe>

L'élément <iframe> (pour inline frame) permet d'incorporer une autre page HTML, un document interactif ou une ressource externe directement à l'intérieur de la page Web courante, formant ainsi une fenêtre de navigation autonome.

1. Syntaxe fondamentale

<iframe src="vision.html" name="mini_sandbox" width="800" height="400">
  Votre navigateur ne supporte pas les iframes.
</iframe>

2. Attributs essentiels

  • src : spécifie l'adresse URL (absolue ou relative) du document à afficher dans le cadre.
  • name : attribue un identifiant de contexte de navigation au cadre, permettant à des hyperliens de le cibler.

3. Mécanisme de ciblage avec l'attribut target

Par défaut, un lien hypertexte s'ouvre dans la fenêtre courante (target="_self") ou dans un nouvel onglet (target="_blank"). En affectant à l'attribut target d'un lien la valeur du name d'un <iframe>, le clic sur ce lien charge immédiatement le document à l'intérieur de ce cadre sans recharger la page principale.

Règle de correspondance : La valeur renseignée dans target="..." sur la balise <a> doit correspondre exactement à la valeur de l'attribut name="..." défini sur la balise <iframe> réceptrice.
Exemple : Manuel numérique avec sommaire interactif

Considérons un manuel de cours en ligne où une barre de navigation permet d'afficher les différents chapitres dans une zone de lecture unique : 

<!-- 1. Liens du sommaire ciblant le cadre "zone_cours" -->
<nav>
  <a href="chapitre1.html" target="zone_cours">Chapitre 1 : Introduction au Web</a> |
  <a href="chapitre2.html" target="zone_cours">Chapitre 2 : Balises HTML5</a> |
  <a href="chapitre3.html" target="zone_cours">Chapitre 3 : Feuilles CSS3</a>
</nav>

<!-- 2. Cadre récepteur identifié par name="zone_cours" -->
<iframe src="chapitre1.html" name="zone_cours" width="100%" height="240">
  Votre navigateur ne supporte pas les cadres intégrés.
</iframe>

Principe d'exécution : Lorsque l'utilisateur clique sur le lien « Chapitre 2 : Balises HTML5 », le navigateur repère le cadre portant name="zone_cours" et y charge la page chapitre2.html sans jamais quitter ni rafraîchir la page principale.

Images adaptatives : <picture> et <source>

L'attribut media conditionne le chargement d'une ressource ou l'application d'une feuille de style selon les caractéristiques du dispositif de consultation (largeur de la fenêtre d'affichage, orientation ou résolution d'écran).

1. Images adaptatives avec <picture> et <source>

Associé à l'élément <picture> et à la balise <source>, l'attribut media permet au navigateur de sélectionner intelligemment l'image la plus appropriée :

  • Sur grand écran (ordinateur de bureau, tablette en mode paysage) : le navigateur télécharge une version Haute Définition (HD) riche en détails.
  • Sur petit écran (smartphone, fenêtre réduite) : le navigateur bascule automatiquement sur une version normale / standard plus légère, accélérant le chargement et économisant la bande passante.
<!-- Chargement adaptatif selon la résolution de l'écran -->
<picture>
  <!-- Image Haute Définition chargée uniquement si la largeur d'écran est >= 768px -->
  <source media="(min-width: 768px)" srcset="images/nano-banana-hd.jpg">

  <!-- Image normale / standard de repli pour les petits écrans et mobiles -->
  <img src="images/nano-banana-normal.jpg" alt="Mascotte Nano Banana" class="img-fluid rounded border shadow-sm">
</picture>
🍌 Démonstration en direct de l'image adaptative (Nano Banana) :

Redimensionnez la largeur de votre fenêtre pour observer le basculement automatique entre la version Haute Définition (≥ 768px) et la version Normale (< 768px) :

1. Version Haute Définition (HD)
Ciblée par media="(min-width: 768px)"
2. Version Normale / Standard
Définie sur la balise de repli <img>

2. Feuilles de style conditionnelles avec <link> ou <style>

L'attribut media peut également être employé sur les balises <link> ou <style> (ex. media="screen") pour restreindre l'application d'une feuille de style aux caractéristiques de l'écran.

Abréviations : <abbr>

En HTML5, la balise sémantique <abbr> (pour abbreviation) est utilisée pour représenter une abréviation, un sigle ou un acronyme (ex. IA, HTML, CSS).

1. Rôle et utilisation de l'attribut title

Pour expliciter le sens d'un terme abrégé, on lui associe systématiquement l'attribut title, qui contient la description ou le développement complet du sigle : 

<p>
  Le standard <abbr title="HyperText Markup Language">HTML5</abbr>
  est maintenu par le <abbr title="World Wide Web Consortium">W3C</abbr>.
</p>

2. Atouts ergonomiques et accessibilité

  • Infobulle native (tooltip) : Le navigateur affiche automatiquement une infobulle explicative lorsque l'internaute survole l'élément avec le pointeur de la souris.
  • Accessibilité (A11y) : Les lecteurs d'écran utilisés par les personnes malvoyantes peuvent énoncer le développement complet du terme au lieu de simplement épeler les lettres.
  • Rendu visuel par défaut : La plupart des navigateurs soulignent le texte délimité par <abbr> d'une fine ligne pointillée discrète (dotted underline) pour inciter au survol.

Code HTML de la démonstration :

<p>
  Un modèle d'<abbr title="Intelligence Artificielle">IA</abbr> applique un algorithme de
  <abbr title="Mécanisme d'ajustement automatique des poids du réseau neuronal">rétropropagation</abbr>
  sur un processeur <abbr title="Graphics Processing Unit - Processeur graphique hautement parallélisé">GPU</abbr>
  pour minimiser l'<abbr title="Écart mesuré entre la prédiction mathématique et la valeur réelle">erreur quadratique</abbr>.
</p>
💡 Rendu dans le navigateur (survolez les termes soulignés avec la souris) :

Un modèle d'IA applique un algorithme de rétropropagation sur un processeur GPU pour minimiser l'erreur quadratique.

Éléments invisibles

HTML5 fournit l'attribut booléen global hidden pour indiquer qu'un élément n'est pas ou n'est plus pertinent pour l'affichage courant.

1. Comportement de l'attribut hidden

Lorsqu'un élément possède l'attribut hidden, le navigateur le retire totalement de l'affichage visuel et libère immédiatement l'espace qu'il aurait dû occuper dans le flux de la page : 

<!-- Paragraphe confidentiel masqué de l'affichage -->
<p hidden>Données de diagnostic interne réservées aux administrateurs.</p>

<!-- Bloc de calcul masqué à l'état initial -->
<div id="bloc-formule" hidden>
  <h4>Formule mathématique</h4>
  <p>y = 0.5 * x + 2.0</p>
</div>

2. Comparaison avec les règles de visibilité CSS

Technique Nature Effet sur l'affichage et l'espace réservé
hidden Attribut natif HTML5 Élément totalement masqué. Ne réserve aucun espace.
display: none; Propriété CSS Retire l'élément du flux d'affichage visuel. Ne réserve aucun espace.
visibility: hidden; Propriété CSS Rend l'élément invisible, mais conserve l'espace blanc qu'il occupe dans la page.

3. Démonstration des trois méthodes de masquage

Pour observer concrètement la différence d'occupation spatiale entre ces trois techniques, considérons une rangée composée de trois éléments consécutifs : Bloc 1, Bloc 2 (l'élément soumis au masquage) et Bloc 3.

Code source HTML & CSS des trois méthodes :
<!-- 1. État initial de référence (les 3 blocs sont visibles) -->
<div class="conteneur">
  <div class="bloc bloc-1">Bloc 1</div>
  <div class="bloc bloc-2">Bloc 2 (Visible)</div>
  <div class="bloc bloc-3">Bloc 3</div>
</div>

<!-- 2. Méthode 1 : Attribut HTML5 hidden -->
<div class="conteneur">
  <div class="bloc bloc-1">Bloc 1</div>
  <div class="bloc bloc-2" hidden>Bloc 2 (hidden)</div>
  <div class="bloc bloc-3">Bloc 3</div>
</div>

<!-- 3. Méthode 2 : Règle CSS display: none -->
<div class="conteneur">
  <div class="bloc bloc-1">Bloc 1</div>
  <div class="bloc bloc-2" style="display: none;">Bloc 2 (display: none)</div>
  <div class="bloc bloc-3">Bloc 3</div>
</div>

<!-- 4. Méthode 3 : Règle CSS visibility: hidden -->
<div class="conteneur">
  <div class="bloc bloc-1">Bloc 1</div>
  <div class="bloc bloc-2" style="visibility: hidden;">Bloc 2 (visibility: hidden)</div>
  <div class="bloc bloc-3">Bloc 3</div>
</div>

Feuilles de style CSS3 avancées

Sélecteurs combinés : element.class

Le sélecteur combiné element.classe cible uniquement une balise HTML précise portant une classe déterminée, sans espace entre le nom de la balise et le point de la classe.

1. Utilité et intérêt pédagogique

Contrairement à un sélecteur de classe simple (.classe) qui s'applique indistinctement à n'importe quel élément, le sélecteur combiné renforce la précision sémantique du style et évite d'impacter par erreur d'autres balises partageant le même nom de classe : 

/* Cible uniquement les balises <table> ayant la classe benchmark-table */
table.benchmark-table {
  width: 100%;
}

/* Cible uniquement les balises <img> ayant la classe filter-preview */
img.filter-preview {
  display: block;
  border-radius: 8px;
}

/* Cible uniquement les balises <figure> ayant la classe carte-filtre */
figure.carte-filtre {
  display: inline-block;
  width: 210px;
}

/* Cible uniquement les balises <span> ayant la classe result-display */
span.result-display {
  font-weight: bold;
  color: #4f46e5;
}
Règle de syntaxe : Ne placez aucun espace entre le nom de l'élément et le point (ex. table.benchmark-table). Un espace (table .benchmark-table) transformerait la règle en un sélecteur descendant, ciblant un élément de classe benchmark-table situé à l'intérieur d'une table !

2. Code source et démonstration pratique

Considérons trois balises HTML différentes (<button>, <a> et <div>) qui partagent la même classe action-element : 

<!-- Même classe action-element, mais balises distinctes -->

Type d'affichage : display

La propriété display définit le comportement de la boîte générée par un élément dans le flux du document et détermine la façon dont il s'insère par rapport aux éléments voisins :

Valeur Comportement dans le flux Exemples HTML natifs
block Occupe toute la largeur disponible. Provoque un retour à la ligne avant et après. Accepte width, height, marges et espacements verticaux. <div>, <p>, <h1>-<h6>, <section>, <figure>
inline S'insère directement dans le texte sans retour à la ligne. N'occupe que la largeur de son contenu. Ignore width et height. <span>, <strong>, <em>, <a>, <code>, <abbr>
inline-block Hybride très pratique : se place côte à côte sur la ligne comme un élément inline, tout en acceptant des dimensions (width, height) et marges comme un élément block. <button>, <input>, cartes d'une galerie
none Supprime complètement l'élément de l'affichage. L'espace qu'il occupait est totalement libéré. Éléments temporairement masqués, menus fermés

Code source et démonstration comparative des modes display

<!-- 1. Éléments de type block (empilement vertical pleine largeur) -->
<div class="demo-item-block">Bloc 1 (display: block)</div>
<div class="demo-item-block">Bloc 2 (display: block)</div>

<!-- 2. Éléments de type inline (dans le texte, dimensions ignorées) -->
<span class="demo-item-inline">Inline A</span>
<span class="demo-item-inline">Inline B</span>

<!-- 3. Éléments de type inline-block (côte à côte avec dimensions respectées) -->
<div class="demo-item-inline-block">Inline-Block 1</div>
<div class="demo-item-inline-block">Inline-Block 2</div>

Positionnement flottant : float

La propriété float détache temporairement un élément du flux normal pour le placer à gauche (float: left;) ou à droite (float: right;) de son conteneur, permettant au texte suivant de s'enrouler autour de lui (effet d'habillage).

Règle fondamentale du programme 3STI : La propriété float s'applique sur des éléments de bloc (ou des éléments configurés avec display: block;).

1. Code source de l'habillage et du rétablissement du flux

<div class="conteneur-flottant">
  <!-- Image de bloc alignée à gauche avec float: left -->
  <img src="images/miniprojet-20.svg" alt="IA" class="img-flottante">
  
  <!-- Texte qui s'enroule autour de l'image -->
  <p>L'apprentissage automatique permet aux ordinateurs d'apprendre à partir de données...</p>
  
  <!-- Séparateur rétablissant le flux sous l'image flottante -->
  <div class="clear-line"></div>
  <p>Ce paragraphe démarre proprement sous l'image grâce à clear: both.</p>
</div>
img.img-flottante {
  display: block;
  float: left;
  width: 100px;
  height: 100px;
  margin-right: 1.25rem;
  margin-bottom: 0.5rem;
  border-radius: 8px;
}

/* Annule l'effet flottant et force le contenu suivant à passer dessous */
.clear-line {
  clear: both;
}

Gestion du débordement : overflow

La propriété overflow détermine le comportement du contenu lorsqu'il dépasse les dimensions fixées (largeur ou hauteur) de sa boîte conteneur :

Valeur Comportement
visible Comportement par défaut : le contenu qui déborde reste visible et empiète sur les éléments voisins.
hidden Le contenu excédentaire est coupé et masqué. Aucune barre de défilement n'apparaît.
scroll Le contenu excédentaire est masqué et des barres de défilement horizontale et verticale sont systématiquement affichées.
auto Recommandé : le navigateur n'affiche une barre de défilement que si le contenu dépasse effectivement la boîte.

.box-auto   { height: 80px; overflow: auto; }

Transparence et opacité : opacity

La propriété opacity applique un degré d'opacité (ou de transparence) global à un élément et à tout son contenu (textes, bordures et images enfants).

1. Échelle de valeurs

Sa valeur est un nombre décimal compris entre 0 et 1 :

  • opacity: 1; : élément 100% opaque (valeur par défaut, aucune transparence).
  • opacity: 0.5; : élément semi-transparent à 50%.
  • opacity: 0; : élément totalement transparent (invisible, mais son espace reste réservé dans la page).

2. Code source et démonstration d'opacité

/* Règle d'opacité statique */
.carte-semi-transparente {
  opacity: 0.7;
}

/* Règle d'opacité interactive avec survol (:hover) */
.carte-interactive {
  opacity: 0.45;
  transition: opacity 0.3s ease;
}
.carte-interactive:hover {
  opacity: 1; /* Retour à 100% au survol */
}

Ombres portées : box-shadow

La propriété box-shadow projette une ombre portée autour du cadre d'un élément, créant une impression de relief et de profondeur visuelle.

1. Syntaxe de la propriété

box-shadow: decalage-x decalage-y flou [etalement] couleur;
  • décalage-x : déplacement horizontal de l'ombre (positif vers la droite, négatif vers la gauche).
  • décalage-y : déplacement vertical de l'ombre (positif vers le bas, négatif vers le haut).
  • flou (blur) : rayon de diffusion du flou gaussien (0 = contour net).
  • étalement (spread, optionnel) : accroissement ou réduction de la taille de l'ombre.
  • couleur : couleur de l'ombre, souvent exprimée en rgba() pour doser la transparence.

2. Code source des différents styles d'ombres

/* 1. Ombre douce d'interface */
.ombre-douce {
  box-shadow: 0 4px 10px rgba(0, 0, 0, 0.1);
}

/* 2. Ombre d'élévation prononcée */
.ombre-elevee {
  box-shadow: 0 12px 24px -4px rgba(15, 23, 42, 0.22);
}

/* 3. Halo lumineux d'accentuation */
.ombre-halo {
  box-shadow: 0 0 18px rgba(6, 182, 212, 0.55);
}

Filtres graphiques : filter

Transitions fluides : transition

La propriété transition permet d'animer progressivement le changement d'une ou plusieurs propriétés CSS d'un état initial vers un nouvel état (notamment lors du survol avec la pseudo-classe :hover).

1. Propriétés détaillées et syntaxe raccourcie

  • transition-property : nom de la propriété CSS à animer (ex. top, box-shadow, opacity ou all).
  • transition-duration : durée de l'animation en secondes (ex. 0.3s) ou millisecondes (ex. 300ms).
  • transition-timing-function : rythme de l'animation (ex. ease, linear, ease-in-out).
  • transition-delay : délai d'attente avant le début de l'animation (optionnel).

2. Code source de l'animation au survol

/* Syntaxe : transition: propriété durée timing; */
button.btn-anime {
  background-color: #4f46e5;
  color: #ffffff;
  padding: 10px 22px;
  border-radius: 8px;
  border: none;
  box-shadow: 0 4px 10px rgba(79, 70, 229, 0.25);
  /* Animation progressive et fluide sur 3 propriétés en 0.3s */
  transition: background-color 0.3s ease, transform 0.3s ease, box-shadow 0.3s ease;
}

button.btn-anime:hover {
  background-color: #06b6d4;                      /* Transition vers le cyan */
  transform: translateY(-4px) scale(1.04);        /* Légère élévation */
  box-shadow: 0 10px 20px rgba(6, 182, 212, 0.4); /* Accentuation de l'ombre */
}

Bordures de tableaux : border-collapse

La propriété border-collapse définit la manière dont le navigateur gère les bordures entre les cellules d'un tableau HTML (<table>).

Valeur Comportement visuel
separate Comportement par défaut : chaque cellule (<th>, <td>) possède sa propre bordure distincte, séparée des cellules voisines par un espace d'écartement.
collapse Recommandé pour un rendu net : les bordures adjacentes des cellules voisines sont fusionnées en une bordure commune unique. L'écartement par défaut est supprimé.

Code HTML et CSS des deux modes de bordures

/* Cas 1 : Bordures séparées avec espacement visible */
table.table-separate {
  border-collapse: separate;
  border-spacing: 5px;
}

/* Cas 2 : Bordures fusionnées en une ligne fine et nette */
table.table-collapse {
  border-collapse: collapse;
}

Disposition des colonnes : table-layout

La propriété table-layout détermine l'algorithme employé par le navigateur pour calculer la largeur des colonnes et la mise en page d'un tableau.

Valeur Comportement et performance
auto Comportement par défaut : le navigateur doit analyser l'intégralité du contenu de toutes les cellules de toutes les lignes avant de fixer la largeur des colonnes. Rendu plus lent sur de grands tableaux.
fixed Disposition fixe et stricte : les largeurs des colonnes sont calculées et figées dès l'analyse de la première ligne d'en-tête (<th>). Rendu beaucoup plus rapide et respect rigoureux des largeurs définies.

Code HTML et CSS d'un tableau à disposition fixe

<table class="tableau-benchmark">
  <thead>
    <tr>
      <th class="col-arch">Architecture (25%)</th>
      <th class="col-usage">Usage principal (45%)</th>
      <th class="col-acc">Précision (15%)</th>
      <th class="col-lat">Latence (15%)</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>ResNet-50</td>
      <td>Reconnaissance d'images et vision artificielle</td>
      <td>94.8%</td>
      <td>12 ms</td>
    </tr>
  </tbody>
</table>
table.tableau-benchmark {
  width: 100%;
  table-layout: fixed;        /* Largeurs fixes imposées dès la 1ère ligne */
  border-collapse: collapse; /* Bordures fusionnées */
}
