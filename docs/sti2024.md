Voici la liste de toutes les notions étudiées en **3ᵉ SI** mentionnées dans le document :

**HTML5**

* **Éléments de 1ᵉʳ niveau** : `<html>`, `<head>`, `<body>`

* **Éléments d'en-tête** : `<meta>` (attributs : *charset, name, content*), `<style>` (attributs : *type, media*), `<title>`, `<link>` (attributs : *href, rel, type*), `<script>` (attributs : *src, type*)


* **Structuration de texte et média** : `<p>`, `<strong>`, `<em>`, `<u>`, `<h>`, `<hr>`, `<br>`, `<mark>`, `<img>` (*src, alt*), `<audio>` (*controls, src*), `<video>` (*controls, src*), `<a>` (*href, target*), `<sup>`, `<sub>`, `<address>`, `<cite>`, `<details>` (*open*), `<summary>`, `<source>` (*src, type, media*), `<figure>`, `<figcaption>`, `<output>`

* **Listes** : `<ul>`, `<ol>` (*reversed, type, start*), `<li>`

* **Tableaux** : `<table>`, `<thead>`, `<tbody>`, `<tfoot>`, `<caption>`, `<tr>`, `<th>`, `<td>`

* **Conteneurs** : `<span>`, `<div>`, `<iframe>` (*src, name*)


* **Structuration d'une page web** : `<header>`, `<nav>`, `<footer>`, `<section>`, `<article>`, `<aside>`, `<main>`

* **Formulaires** :
* Éléments : `<form>` (*action, method="post"/"get", target*), `<fieldset>`, `<legend>`, `<label>`, `<textarea>` (*id, cols, rows, readonly, required, disabled, placeholder*), `<select>`, `<option>` (*id, name, size, disabled, value, selected*)


* Types de l'élément `<input>` : *text, email, password, tel, number, date, range, time, checkbox, radio, submit, reset, button*



* **Attributs globaux** : `class`, `hidden`, `id`, `lang`, `title`

* **Événements** : `onfocus`, `onblur`, `onclick`, `oninput`, `onchange`, `onload`


---

**CSS3**

* **Sélecteurs** : `*` (universel), `element`, `#id`, `.class`, `element.class`

* **Mise en forme du texte** : `font`, `text-align`, `color`, `text-transform`

* **Arrière-plan** : `background`

* **Images** : `filter`

* **Tableaux** : `table-layout`, `border-collapse`

* **Boîtes (Modèle de boîte & positionnement)** : `width`, `height`, `position`, `float`, `padding`, `margin`, `box-shadow`, `display`, `top`, `bottom`, `left`, `right`, `overflow`, `opacity`

* **Bordures** : `border`

* **Transition & Animation** : `transition`, `animation`


---

**JavaScript**

* **Opérateurs** :
* Logiques : `||`, `&&`, `!`

* Arithmétiques : `+`, `-`, `*`, `/`, `%`

* Comparaison : `==`, `<`, `<=`, `>`, `>=`, `!=`

* Chaînes : `+` (concaténation)




* **Affichage & Saisie** : `alert()`, `document.write()`, `innerHTML`, `prompt()`

* **Manipulation des chaînes de caractères** :
* Méthodes : `ch.length`, `ch.indexOf(ch1, p)`, `ch.lastIndexOf(ch1, p)`, `ch.substring(d, f)`, `ch.replace(ch1, ch2)`, `ch.toUpperCase()`, `ch.toLowerCase()`, `ch.trim()`, `String.fromCharCode(...)`, `ch.charCodeAt(p)`

* Accès aux caractères : `ch[p]`, `charAt(p)`



* **Nombres** : `isNaN(ch)`, `Number(ch)`, `parseFloat(ch)`, `parseInt(ch, b)`, `N.toString()`

* **Objet Math** : `abs(N)`, `round(N)`, `trunc(N)`, `random()`

* **Objet Date** : `new Date()`, `new Date(ch)`, `d.getDate()`, `d.getMonth()`, `d.getFullYear()`, `d.toString()`

* **Objet Array** : propriété `length`

* **DOM (Accès et manipulation de base)** :
* Accès : `getElementById("Id")`, `getElementsByName("nom")`

* Manipulation :
* `document.getElementById("Id").value = valeur`

* `document.getElementById("Id").checked = true/false`

* `document.getElementById("Id").selectedIndex`

* `document.getElementById("Id").selectedIndex = valeur`






---

**SQL**

* **Définition des données (DDL)** :
* `CREATE DATABASE nom`, `DROP DATABASE nom`

* `CREATE TABLE table1 (...)`

* `ALTER TABLE table1 ADD colonne type [contrainte]`

* `ALTER TABLE table1 DROP colonne`

* `ALTER TABLE table1 ALTER colonne type` (ou `MODIFY`)


* `ALTER TABLE table1 RENAME nom1 TO nom2` (ou `CHANGE`)


* `ALTER TABLE table1 ADD CONSTRAINT [nom] contrainte`

* `ALTER TABLE table1 DROP CONSTRAINT nom`

* `ALTER TABLE table1 ENABLE/DISABLE CONSTRAINT nom`

* `DROP TABLE table1`



* **Manipulation des données (DML/DQL)** :
* `SELECT [DISTINCT] ... FROM ... [WHERE ...] [ORDER BY ...]`

* `INSERT INTO table [(colonnes)] VALUES (...)`

* `UPDATE table1 SET colonne = expression [WHERE condition]`

* `DELETE FROM table1 [WHERE condition]`



* **Opérateurs** :
* Comparaison : `=`, `!=` (ou `<>`), `>`, `<`, `>=`, `<=`, `IN`, `BETWEEN`, `LIKE`, `IS`

* Logiques : `AND`, `OR`, `NOT`



* **Fonctions sur le type Date** : `DATE()`, `DAY()`, `MONTH()`, `YEAR()`, `NOW()`, `ADDDATE()`, `DATEDIFF()`

* **Types de données** : `INT`, `DECIMAL`, `CHAR`, `VARCHAR`, `TEXT`, `DATE`, `TIME`, `DATETIME`

* **Contraintes d'intégrité** : `NOT NULL`, `DEFAULT`, `CHECK`, `PRIMARY KEY`, `UNIQUE`, `FOREIGN KEY`, `REFERENCES`, `ON UPDATE CASCADE`, `ON DELETE CASCADE`
