JavaScript — Série d'exercices n°2 : Formulaires et <div>

Présentation

Pourquoi cette séance ?

Classe : 3e info Durée : 2 heures Séance 3 — 6 exercices progressifs

Jusqu'ici, vous entriez les données avec prompt() et vous répondiez avec alert(). C'était une bonne première étape, mais ce n'est pas ainsi qu'une vraie page web fonctionne. Aujourd'hui, vous franchissez un cap : l'utilisateur écrit dans la page (un formulaire : <form>) et le résultat s'affiche dans la page (un <div>).

Rassurez-vous : vous gardez tout ce que vous savez déjà — variables, Number(), if / else, boucles, fonctions et Math.trunc(). Vous ajoutez une seule idée nouvelle, en deux moitiés faciles à retenir :

  • Lire : accéder à un composant de formulaire pour récupérer sa valeur.
  • Écrire : accéder aux propriétés d'un <div> pour y afficher un texte et changer son apparence.

Objectifs de la séance

  • Retrouver un élément de la page grâce à son id avec document.getElementById("...").
  • Créer un formulaire avec la balise <form>, puis lire la valeur de ses composants : champ texte, nombre ou date, liste déroulante, bouton radio, case à cocher.
  • Convertir une valeur lue en nombre avec Number() avant tout calcul.
  • Afficher un résultat dans un <div> avec innerHTML, avec ou sans balises comme <br>.
  • Modifier l'apparence d'un <div> : style.color, style.backgroundColor, style.fontSize, style.display, et réagir au clic sur un bouton avec une fonction.

Cours express

1. Structure d'une page et composants de formulaire

Toutes les pages de cette fiche suivent le même plan simple : d'abord les composants, regroupés dans un formulaire <form>, ensuite le script qui lit, calcule et affiche. 

<!DOCTYPE html>
<html>
<head><meta charset="utf-8"><title>Ma page</title></head>
<body>
  <!-- 1. Les composants : ce que l'utilisateur remplit -->
  <form>
    <input type="number" id="n1">
    <button onclick="traiter()">Valider</button>
    <div id="resultat"></div>
  </form>
  <script>
    // 2. Le script : il lit, il traite, il affiche
    function traiter() {
      let n = Number(document.getElementById("n1").value);
      document.getElementById("resultat").innerHTML = "Le double : " + (n * 2);
    }
  </script>
</body>
</html>
Le point clé de la séance : le lien entre le HTML et le JavaScript, c'est l'id. Le nom écrit dans getElementById("...") doit être exactement celui de l'attribut id.

Les composants de formulaire à connaître

Composant Code HTML À quoi il sert
Formulaire <form>...</form> Regroupe tous les composants de saisie.
Champ texte <input type="text" id="nom"> Saisir un texte libre (nom, ville...).
Champ nombre <input type="number" id="prix"> Saisir un nombre ; n'accepte que des chiffres.
Liste déroulante <select id="ville">...</select> Choisir une valeur dans une liste.
Bouton radio <input type="radio" name="g" id="g1" value="..."> Choisir une seule réponse parmi plusieurs ; chaque bouton a son id.
Case à cocher <input type="checkbox" id="accord"> Répondre oui ou non (coché / non coché).
Bouton <button onclick="f()">Clic</button> Déclencher la fonction f() au clic.

Les boutons radio : la règle du groupe

Tous les boutons d'un même groupe portent le même attribut name : un seul peut alors être coché à la fois. Chacun a son value et son propre id : c'est cet id qui vous permettra de tester, avec .checked, quel bouton est coché. L'attribut checked coche l'un d'eux dès l'ouverture. 

<input type="radio" name="op" id="opPlus" value="+" checked> Addition
<input type="radio" name="op" id="opMoins" value="-"> Soustraction

2. Lire la valeur d'un composant

La forme générale est toujours la même : vous retrouvez le composant par son id, puis vous lisez la propriété qui contient sa réponse. 

document.getElementById("idDuComposant").value
On veut lire... On écrit...
Un champ texte ou nombre document.getElementById("nom").value
La valeur choisie dans une liste déroulante document.getElementById("ville").value
Si une case est cochée (true / false) document.getElementById("accord").checked
Quel bouton radio est coché dans un groupe Testez chaque bouton par son id avec .checked :
if (document.getElementById("g2").checked) { choix = document.getElementById("g2").value; }
Attention, piège n°1 : .value donne toujours une chaîne de caractères, même pour un champ nombre. "17" + "5" donne "175", pas 22. Avant tout calcul, convertissez toujours : let a = Number(document.getElementById("n1").value);

La liste déroulante en détail

<form>
  <select id="ville">
    <option value="Sousse">Sousse</option>
    <option value="Tunis">Tunis</option>
  </select>
</form>

Ce que lit le script, c'est l'attribut value de l'option choisie. Le value et le texte affiché peuvent être différents : <option value="TN">Tunisie</option> affiche « Tunisie » et le script lit "TN".

Le schéma complet d'un traitement

Étape Question à se poser Ligne type
1. Retrouver Quel est l'id du composant ? document.getElementById("naissance")
2. Lire Texte, nombre ou case cochée ? .value, Number(...), .checked
3. Traiter Calcul, test ou boucle ? if, for, opérations habituelles
4. Afficher Où et comment afficher le résultat ? innerHTML dans le div, puis style

Le champ date en détail (pour l'exercice 2)

<form><input type="date" id="naissance"></form>
<script>
  let naissance = new Date(document.getElementById("naissance").value);
  let auj = new Date(); // la date du jour
</script>

La valeur lue est une chaîne au format « AAAA-MM-JJ », vide si aucune date n'a été choisie. new Date(...) la transforme en vraie date, dont on extrait l'année par getFullYear(), le mois par getMonth() et le jour par getDate(). Pour calculer un âge, procédez en deux temps : faites d'abord la différence des années, puis retirez 1 si l'anniversaire n'est pas encore passé cette année.

3. Accéder aux propriétés d'un <div>

Un <div> est une zone vide de la page, que votre script remplit et met en forme. Vous le retrouvez par son id, puis vous modifiez ses propriétés. Dans les exemples, d désigne ce div : 

let d = document.getElementById("resultat");

3.1 Afficher un contenu : la propriété innerHTML

Propriété Exemple Effet
innerHTML d.innerHTML = "Bonjour"; Un texte simple s'affiche tel quel.
innerHTML (avec balises) d.innerHTML = "<b>Bonjour</b>"; Balises interprétées : gras, retour à la ligne. Toujours innerHTML.

3.2 Changer l'apparence : la propriété style

Propriété Exemple Effet
style.color d.style.color = "red"; Couleur du texte.
style.backgroundColor d.style.backgroundColor = "#ffe9a8"; Couleur de fond de la zone.
style.fontSize d.style.fontSize = "20px"; Taille du texte (ne pas oublier px).
style.fontWeight d.style.fontWeight = "bold"; Texte en gras.
style.textAlign d.style.textAlign = "center"; Alignement : left, center, right.
style.padding d.style.padding = "10px"; Espace intérieur autour du texte.
style.border d.style.border = "2px solid blue"; Bordure : épaisseur, style, couleur.
style.display d.style.display = "none"; "none" cache la zone ; "block" la réaffiche.
Attention, piège n°2 : les noms composés s'écrivent sans tiret et avec une majuscule : backgroundColor, fontSize, textAlign. Écrire background-color dans un script est une erreur.
Réflexe à garder pour tous les exercices : 1) retrouvez les composants par leur id ; 2) lisez leurs valeurs (avec Number() si c'est un nombre) ; 3) calculez ou testez ; 4) affichez dans le div et réglez son style.
Mini-test éclair (à l'oral, 2 minutes)
  1. Quelle ligne lit le nombre écrit dans le champ d'id taille ?
  2. Quelle propriété faut-il utiliser pour qu'un <br> crée vraiment une nouvelle ligne dans le div ?
  3. Comment cache-t-on le div d'id msg, puis comment le réaffiche-t-on ?

Réponses : 1) Number(document.getElementById("taille").value) — 2) innerHTML — 3) style.display = "none" puis "block".

Exercice 1

Exercice 1 : La calculatrice à boutons radio

Découverte guidée

À vous de construire, pas à pas, une calculatrice complète dans la page. L'utilisateur saisit deux nombres, choisit l'opération, clique, et le résultat s'affiche dans un div. Ce premier exercice est fait pour vous rassurer : vous utilisez uniquement des nombres et des opérations déjà connus, avec deux nouveautés seulement : trouver le bouton radio coché et écrire dans un div.

Les composants de la page, à placer entre <form> et </form> :
  • deux champs nombre, d'id n1 et n2 ;
  • quatre boutons radio de name op, d'id opPlus, opMoins, opFois et opDiv, de valeurs +, -, * et /, affichés « Addition », « Soustraction », « Multiplication », « Division » ; le bouton + porte l'attribut checked ;
  • un bouton « Calculer » qui appelle la fonction calculer() ;
  • un div d'id resultat.
Travail demandé — suivez les étapes dans l'ordre, chacune prépare la suivante :
  1. Dans la fonction, commencez par lire les deux nombres avec Number(). Trouvez ensuite l'opérateur choisi : testez .checked de chaque bouton radio par son id, un par un — le bouton coché est celui que l'utilisateur a choisi, et son value vous donne l'opérateur.
  2. Calculer le résultat selon l'opérateur, avec un if / else if à quatre branches.
  3. Affichez dans le div, avec innerHTML, l'opération complète et son résultat, par exemple : « 17 + 5 = 22 ».
  4. Mettre le div en gras, avec un padding de 10px et un fond bleu clair.
  5. Cas particulier : si l'opérateur est / et que le deuxième nombre vaut 0, afficher à la place, en rouge : « Division par zéro impossible. » (et remettre le fond du div en rouge très clair).
Tests à réussir — vérifiez-les un par un : 17 et 5 donnent 22 (addition), 12 (soustraction), 85 (multiplication) et 3,4 (division). Avec 17, 0 et la division choisie, le message rouge s'affiche.
Ce que voit l'utilisateur : deux cases pour les nombres, quatre ronds pour choisir l'opération, un bouton, puis la réponse écrite dans la page. Aucun prompt(), aucun alert() : tout se passe dans la page, comme dans une vraie calculatrice en ligne.
Si la somme affiche 175 au lieu de 22 : c'est le piège n°1. Les deux valeurs sont restées des chaînes de caractères. Vérifiez d'abord les deux Number() avant de chercher ailleurs : neuf fois sur dix, l'erreur est là.

Exercices 2 & 3

Exercice 2 : Le formulaire nom et date de naissance

Après les nombres, les personnes, en douceur : vous ne demandez plus l'âge, mais la date de naissance : c'est votre script qui calcule l'âge. La page contient un formulaire (<form>...</form>) avec un champ texte d'id nom, un champ date d'id naissance, un bouton « Présenter » et un div d'id presentation.

  1. Au clic, lire le nom (texte, sans conversion) et la date de naissance (chaîne « AAAA-MM-JJ », vide si aucune date n'a été choisie).
  2. Si le nom est vide ou si la date est vide, afficher uniquement, en rouge : « Écrivez votre nom et votre date de naissance. »
  3. Sinon, calculer l'âge : transformer la chaîne en date avec new Date(...), prendre la date du jour avec new Date(), faire la différence des années (getFullYear()), puis retirer 1 si l'anniversaire n'est pas encore passé cette année.
  4. Afficher dans le div, sur trois lignes grâce à innerHTML et <br> : « Bonjour, je m'appelle [nom] et j'ai [âge] ans. », puis « L'an prochain, j'aurai [âge + 1] ans. », puis « Je suis mineur. » si l'âge calculé est inférieur à 18, « Je suis majeur. » sinon.
Le piège de l'anniversaire : né le 15 décembre 2012, on a encore 13 ans fin novembre 2026, et non 14 : 2026 - 2012 = 14 surestime l'âge tant que l'anniversaire n'est pas passé.
Tests (fin novembre 2026) : « Lina », née le 15 mars 2013, donne 13 ans, « Je suis mineur. » et « L'an prochain, j'aurai 14 ans. ». Née le 10 janvier 2006, elle a 20 ans : « Je suis majeur. ».

Exercice 3 : Un div qui change de couleur, de taille et de texte

Cette fois, le formulaire ne sert pas à calculer : il sert à commander l'apparence d'un div. La page contient, dans un formulaire (<form>...</form>) :

  • un champ texte d'id texte (le texte à afficher) ;
  • trois boutons radio de name couleur, de valeurs red, green et blue ;
  • trois boutons radio de name taille, de valeurs 14px, 20px et 28px, affichés « Petit », « Moyen », « Grand » ;
  • une case à cocher d'id gras (« Texte en gras ») ;
  • un bouton « Appliquer » et un div d'id apercu.
  1. Au clic, recopiez le texte saisi dans le div, avec innerHTML.
  2. Testez .checked de chaque bouton, par son id (couleur : rouge, vert, bleu ; taille : petit, moyen, grand), puis appliquez la couleur (style.color) et la taille (style.fontSize) au div.
  3. Si la case est cochée, mettre le texte en gras ; sinon, le remettre en normal (fontWeight = "normal").
  4. Donner au div, dans tous les cas, un fond gris très clair, un padding de 12px et une bordure fine.
  5. Testez plusieurs combinaisons : changez un seul réglage à la fois et observez ce qui change dans le div.
Test : texte « Vive le JavaScript », couleur bleue, taille Grand, case cochée : le div affiche le texte en bleu, en 28px, en gras, sur fond gris clair.

Exercices 4 & 5

Exercice 4 : Convertisseur avec liste déroulante

La page contient, dans un formulaire (<form>...</form>), un champ nombre d'id montant, une liste déroulante d'id sens avec deux options (value="dt-eur" : Dinars vers Euros ; value="eur-dt" : Euros vers Dinars), un bouton « Convertir » et un div d'id conv. Taux fixe pour l'exercice : 1 euro = 3,4 dinars.

  1. Lire le montant et le sens choisi, puis afficher le résultat tronqué à l'entier avec Math.trunc() : par exemple « 100 dinars = 29 euros. »
  2. Centrer le texte du div, lui donner un fond bleu clair, un padding de 10px et une bordure bleue.
Tests : 100 dinars vers euros donne 29 euros (100 / 3,4 = 29,41... tronqué à 29). 50 euros vers dinars donne 170 dinars.

Exercice 5 : Générer une table de multiplication dans un div

Approfondissement

La page contient, dans un formulaire (<form>...</form>), un champ nombre d'id base, un bouton « Générer » et un div d'id table.

  1. Au clic, construire dans une variable chaîne la table de multiplication du nombre saisi, de 1 à 10, avec une boucle for : une ligne par multiplication, séparées par <br>.
  2. Commencer la chaîne par un titre en gras : « Table de [base] », suivi d'un <br>.
  3. Affichez la chaîne dans le div avec innerHTML, et expliquez en commentaire dans le code pourquoi innerHTML est indispensable ici : sans lui, les <br> et les <b> ne créeraient ni retour à la ligne, ni gras.
  4. Si le nombre saisi est inférieur à 1 ou supérieur à 20, afficher uniquement, en rouge : « Choisissez un nombre entre 1 et 20. »
Tests : base = 7 affiche « Table de 7 », puis 7 x 1 = 7 jusqu'à 7 x 10 = 70. Base = 25 affiche le message rouge.

Exercice 6

Exercice 6 : Mini-projet — Inscription à un club

Synthèse — en binôme

Dernier défi, en binôme : un club de l'établissement recrute. Vous avez déjà toutes les notions qu'il faut ; ce projet les rassemble simplement. La page d'inscription contient un formulaire (<form>...</form>) avec :

  • un champ texte d'id nomc (nom complet) ;
  • un champ nombre d'id agec ;
  • une liste déroulante d'id activite avec trois options : Robotique, Théâtre, Échecs ;
  • deux boutons radio de name niveau, d'id niveauDeb et niveauConf : Débutant (coché par défaut) et Confirmé ;
  • une case à cocher d'id reglement (« J'accepte le règlement du club ») ;
  • un bouton « S'inscrire » et un div d'id bilan.
Travail demandé :
  1. Si le nom est vide, ou si l'âge est inférieur à 11 ou supérieur à 19, ou si la case du règlement n'est pas cochée : afficher dans le div, en rouge sur fond rouge très clair, la liste des problèmes détectés, un par ligne. Le script doit signaler tous les problèmes présents, pas seulement le premier : utiliser trois if indépendants qui ajoutent chacun leur ligne à une chaîne, pas un else if.
  2. Sinon, afficher un résumé complet sur fond vert clair, en vert foncé, chaque information sur sa propre ligne : « Inscription enregistrée. / Nom : ... / Âge : ... ans. / Activité : ... / Niveau : ... »
  3. Ajouter une ligne au résumé : « Groupe : Junior » si l'âge est inférieur à 15, « Groupe : Senior » sinon.
Tests : nom vide + âge 25 + case non cochée donne trois lignes de problèmes. Nom « Lina », âge 13, activité Échecs, niveau Débutant, case cochée donne le résumé vert avec « Groupe : Junior ». La même inscription à 16 ans donne « Groupe : Senior ».
Avant de commencer le projet : prenez deux minutes pour relire le schéma en quatre étapes (retrouver, lire, traiter, afficher). Vous verrez : le projet n'utilise aucune notion nouvelle, il combine simplement la calculatrice (lire et calculer), le formulaire nom et date de naissance (lire un texte et une date, calculer un âge) et le div personnalisé (afficher avec un style).

Aide & Bilan

Erreurs fréquentes, aide-mémoire et bilan

Erreurs fréquentes — à vérifier par vous-même avant d'appeler le professeur

Symptôme Cause probable et remède
Les composants sont écrits en vrac dans la page Il manque le formulaire : tout composant de saisie doit être placé entre <form> et </form>.
Rien ne se passe au clic Le nom dans getElementById("...") ne correspond pas à l'id du HTML, ou le nom de la fonction dans onclick est mal orthographié. Comparer lettre par lettre.
La somme colle les nombres (17 et 5 donnent 175) Valeurs lues sans Number() : ce sont des chaînes. Convertir dès la lecture.
Le calcul se fait toujours avec le même opérateur Un seul bouton radio a été testé, ou les boutons n'ont pas le même name. Testez .checked de chaque bouton du groupe, par son id, un par un.
Les deux boutons radio d'un groupe peuvent être cochés ensemble Ils n'ont pas le même name. Le groupe se reconnaît au name commun.
Le résultat s'affiche sur une seule ligne, sans retour à la ligne Les <br> manquent dans la chaîne affichée. Ajoutez un <br> entre chaque ligne et affichez la chaîne complète avec innerHTML.
Le style ne change pas Nom de propriété écrit avec un tiret (background-color) ou valeur sans unité (fontSize = "20" au lieu de "20px").
La taille du div ne change pas dans l'exercice 3 Les valeurs du groupe taille doivent contenir l'unité : 14px, 20px, 28px. Un nombre seul ne suffit pas.
Le div reste invisible Il était caché par display:none et le script n'a pas remis display = "block".
Un seul problème s'affiche dans l'exercice 6 Les contrôles sont enchaînés avec else if. Les remplacer par des if indépendants qui accumulent les messages.
L'âge affiché a un an de trop dans l'exercice 2 L'anniversaire n'est pas encore passé cette année : la simple différence des années surestime l'âge. Retirer 1 dans ce cas.

Bilan : ce que vous savez faire maintenant
