Mission Pratique Durée recommandée : 20 - 30 minutes

Conception d'une Chronique Littéraire Interactive

Votre mission consiste à transformer un extrait brut de texte en une page web sémantique et interactive consacrée au roman Le Petit Prince d'Antoine de Saint-Exupéry. Vous devez intégrer judicieusement les 7 balises étudiées.

Spécifications techniques à respecter :

  • <figure> & <figcaption> Encapsuler l'image de couverture avec sa légende explicative.
  • <details> & <summary> Créer un accordéon cliquable masquant/affichant les thèmes majeurs du livre.
  • <mark> Mettre en évidence la phrase philosophique clé du renard.
  • <cite> Désigner correctement le titre du chef-d'œuvre et le recueil de citations.
  • <address> Structurer les coordonnées de contact de la rédaction littéraire en fin d'article.

Consigne pour l'apprenant :

Ouvrez l'onglet « Éditeur & Testeur ». Le texte brut y est déjà pré-chargé. Ajoutez les balises appropriées au bon endroit sans casser la mise en page.

Le système vérifiera automatiquement au fur et à mesure que les 7 balises requises sont correctement intégrées et fonctionnelles !

Fiche Récapitulative : 7 Balises Clés

Explications synthétiques, cas d'usage précis et pièges fréquents à éviter.

<figure> + <figcaption>

Rôle : Isole un contenu autonome (image, graphique, extrait de code, schéma) et lui adjoint une légende explicative grâce à <figcaption>.

Règle : <figcaption> doit être le premier ou le dernier enfant direct de <figure>. 

<figure>
  <img src="cover.jpg" alt="Couverture">
  <figcaption>Fig 1. Édition originale de 1943.</figcaption>
</figure>
<details> + <summary>

Rôle : Crée un widget interactif de divulgation (accordéon) natif sans avoir besoin d'écrire une seule ligne de JavaScript !

Règle : <summary> définit le titre cliquable toujours visible. L'attribut optionnel open déplie l'accordéon par défaut. 

<details>
  <summary>Découvrir les thèmes clés</summary>
  <p>L'amitié, la solitude, le voyage...</p>
</details>
<mark>

Rôle : Représente du texte surligné ou mis en exergue en raison de sa pertinence contextuelle (ex : résultat d'une recherche, passage clé).

Piège à éviter : Ne pas confondre avec <strong> (importance sémantique) ou <em> (insistance à l'oral). 

<p>Retenez bien : <mark>L'essentiel est invisible pour les yeux.</mark></p>
<cite>

Rôle : Sert à marquer le titre d'une œuvre (livre, film, tableau, chanson, essai, rapport, opéra, etc.).

Règle capitale HTML5 : La balise <cite> ne doit jamais contenir le nom d'une personne physique (l'auteur), uniquement le titre de l'œuvre. 

<p>Selon le roman <cite>Le Petit Prince</cite> écrit par Saint-Exupéry...</p>
<address>

Rôle : Fournit les informations de contact (e-mail, téléphone, adresse postale, lien réseau social) de l'auteur de l'article ou du propriétaire de la page.

Piège à éviter : Elle ne sert pas à formater n'importe quelle adresse géographique (ex: l'adresse d'un restaurant dont parle un blog), mais bien les coordonnées de l'auteur ou du responsable éditorial. 

<address>
  Chronique rédigée par <a href="mailto:redaction@critique.fr">Sophie Martin</a>.<br>
  Éditions Culturelles, 12 rue des Lettres, Paris.
</address>

Solution Modèle Commentée

Code HTML propre, sémantique et respectant rigoureusement les normes W3C.

<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <title>Chronique Littéraire : Le Petit Prince</title>

        body { font-family: Arial, sans-serif; line-height: 1.6; max-width: 700px; margin: 2rem auto; padding: 0 1rem; color: #222; }

        figure img { max-width: 100%; height: auto; border-radius: 8px; box-shadow: 0 4px 6px rgba(0,0,0,0.1); }
        figcaption { font-size: 0.85rem; color: #666; margin-top: 0.5rem; font-style: italic; }
        details { background: #f8fafc; border: 1px solid #e2e8f0; border-radius: 6px; padding: 0.75rem 1rem; margin: 1.5rem 0; cursor: pointer; }

        mark { background-color: #fef08a; padding: 0.1rem 0.3rem; border-radius: 3px; }
        cite { font-style: italic; color: #1e3a8a; }
        address { margin-top: 2.5rem; border-top: 1px solid #eee; padding-top: 1rem; font-size: 0.85rem; color: #64748b; font-style: normal; }
    </style>
