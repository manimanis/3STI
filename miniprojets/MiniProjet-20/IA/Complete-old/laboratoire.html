Laboratoire IA

Trois expériences pour toucher l'IA du doigt... et le HTML avec elle.

Bienvenue dans le laboratoire ! Ici, tu ne lis plus seulement : tu agis. Classifie des images comme un modèle de vision par ordinateur, ajuste le niveau de confiance d'une IA, et regarde une animation générée pour le site. Chaque activité illustre aussi une balise HTML du programme.

Activité 1 : classifier une image

La classification consiste à ranger une donnée dans une catégorie. Un modèle de vision observe des indices (forme des oreilles, présence de moustaches, couleur du bec...) puis choisit une classe. À toi de jouer : clique sur un animal ci-dessous, et sa fiche descriptive s'affichera dans la zone intégrée de cette page, sans quitter le laboratoire.

Chat Chien Oiseau

Rôle de l'attribut src : il donne l'adresse du document affiché dans l'iframe au chargement de la page. Ici : src="chat.html".

Rôle de l'attribut name : il donne un nom à la zone. Les liens target="zone-fiche" s'en servent pour choisir où s'ouvre leur document : c'est un « rendez-vous » entre le lien et la fenêtre.

Activité 2 : le niveau de confiance de l'IA

Une IA n'affirme pas : elle estime. Quand elle classe une image, elle accompagne sa réponse d'un pourcentage de confiance : « chat, à 82 % ». Déplace le curseur ci-dessous pour te mettre à la place du modèle et ajuster sa certitude.

Confiance du modèle : 82 %

Rôle de la balise <output> : elle affiche le résultat produit par un formulaire (un calcul, une valeur de curseur, une somme...). C'est la balise sémantique du « résultat » : contrairement à une simple balise <span>, elle dit au navigateur et aux lecteurs d'écran que ce nombre EST le résultat du formulaire.

Activité 3 : ressources multimédias

L'IA est aussi une affaire d'images et de sons. Cette animation, dessinée pour le site, illustre un réseau de neurones en activité. Elle est proposée en deux tailles : le navigateur choisit automatiquement la bonne grâce à l'attribut media.

Rôle de l'attribut media : sur une balise <source>, il fixe la condition d'utilisation du fichier : grand écran (media="(min-width:800px)") ou petit écran (media="(max-width:799px)"). On trouve aussi media="screen" sur la balise <style>, comme dans le <head> de la page Modèles IA : même attribut, même logique.

Notions HTML et CSS utilisées sur cette page

iframe src name target input type="range" output video + source type media

Exemple : la zone intégrée et le lien qui la pilote

<a href="chien.html" target="zone-fiche">Chien</a>
<iframe src="chat.html" name="zone-fiche"></iframe>
<!-- src : document affiché au départ | name : cible des liens -->

Exemple : la vidéo adaptative et son résultat

<source src="media/ia-animation-hd.mp4" type="video/mp4" media="(min-width:800px)">
<output for="curseur-confiance">82</output>

À retenir

  • <iframe> : une page HTML intégrée dans une autre page, comme une fenêtre posée sur le document.
  • src : l'adresse du contenu affiché dans l'iframe (ou la vidéo) dès le chargement.
  • name : le nom de la zone ; les liens utilisent target pour y ouvrir leur document.
  • <output> : la balise qui affiche le résultat d'un formulaire ou d'un calcul.
  • media : la condition d'utilisation d'une ressource (largeur d'écran pour une vidéo, type d'affichage pour un style).
