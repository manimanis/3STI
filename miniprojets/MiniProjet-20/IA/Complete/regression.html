La régression linéaire trouve la ligne optimale qui relie une variable explicative (ex: taille des données en Go) à une valeur prédite (ex: temps d'entraînement ou puissance nécessaire).

Temps d'entraînement calculé par l'IA : 50 min

📐 Formule mathématique sous le capot

Le modèle applique l'équation linéaire : y = (a * x) + b

  • x : Taille des données (Go)
  • a (pente / coefficient directeur) = 0.5
  • b (ordonnée à l'origine / biais) = 2.0

Ce texte de diagnostic interne est masqué via l'attribut global booléen hidden.
