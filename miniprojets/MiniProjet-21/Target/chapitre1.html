🌐 Introduction au Web & Architecture Client-Serveur

Le Web repose sur un modèle d'échange décentralisé où deux entités communiquent au moyen du protocole HTTP/HTTPS :

  • 1. Le Client (Navigateur Web) : Envoie une requête HTTP vers un serveur pour solliciter une ressource identifiée par une URL (Uniform Resource Locator).
  • 2. Le Serveur Web : Traite la requête et retourne le document demandé (code source HTML, images, feuilles CSS).
  • 3. Le Moteur de rendu : Le navigateur interprète le balisage HTML et les styles CSS pour afficher la page à l'écran.
💡 Repère historique : Le World Wide Web a été inventé en 1989 par Tim Berners-Lee au CERN pour faciliter le partage de documents entre scientifiques.
