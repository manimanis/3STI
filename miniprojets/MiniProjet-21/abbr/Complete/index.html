🧪 3. Comparatif des 3 techniques de masquage (HTML & CSS)

Comparaison directe de l'impact spatial de chaque technique sur le Nœud Bêta (2) au sein d'une rangée de trois serveurs :

1. État de référence Visible
Nœud Alpha
Nœud Bêta (Visible)
Nœud Gamma

Les 3 nœuds occupent normalement leur place dans la rangée.

2. Attribut HTML5 hidden hidden
Nœud Alpha
Nœud Bêta (hidden)
Nœud Gamma

Nœud Bêta masqué et espace libéré : Gamma se colle contre Alpha.

3. Propriété CSS display: none; display: none
Nœud Alpha
Nœud Bêta (display: none)
Nœud Gamma

Nœud Bêta exclu de l'arbre de rendu : l'espace est libéré.

4. Propriété CSS visibility: hidden; visibility: hidden
Nœud Alpha
Nœud Bêta (visibility: hidden)
Nœud Gamma

Nœud Bêta invisible, mais son espace reste réservé (trou vide visible).
